Regras de leitura dos números

  • Ausência de dado não é zero. Quando a base não informa um valor, a tela mostra sem dado — e o motivo, quando a base registra a flag is_*_missing. Nenhuma tela preenche lacuna com 0 nem deixa célula vazia ambígua.
  • Oferta por etapa é tri-estado. Sim significa matrícula maior que zero; Não significa zero declarado; Desconhecido significa que a base não informou a oferta daquela etapa. {{ explicacao_oferta_desconhecida }}
  • {{ rotulo_retencao }}. {{ definicao_retencao }}
  • Comparação de concorrência é municipal. {{ definicao_concorrencia }}. Não há comparação por distância.
  • Educação básica é total oficial. A etapa Educação básica (bas) é o total publicado pelo Censo; nunca é obtida somando as subetapas.
