{# Breadcrumb das telas de detalhe (achado B7): texto + links, sem JS. "Busca" é a entrada do front; o último item é a tela atual e **não** é link — apontar para a própria página só adiciona um alvo que não leva a lugar nenhum. O nome do último item vem sempre do contexto (`itens[-1]`), então quem chama passa os dados e não o HTML. Uso: {% from "partials/breadcrumb.html" import breadcrumb with context %} {{ breadcrumb([{"rotulo": "Busca", "href": href_busca}, {"rotulo": "Mercado do município", "href": href_mercado}, {"rotulo": municipio_rotulo}]) }} #} {% macro breadcrumb(itens) -%}
    {% for item in itens %}
  1. {%- if item.href -%} {{ item.rotulo }} {%- else -%} {{ item.rotulo }} {%- endif -%}
    2. {% endfor %}
{%- endmacro %}
