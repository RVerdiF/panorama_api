De onde vêm os dados

Os números vêm do Censo Escolar da Educação Básica, levantamento anual do INEP que cobre todas as escolas do país. O Panorama Escola recorta Minas Gerais e publica os anos {{ recorte_anos }}. Quando um dado não existe na base, a tela mostra “sem dado”, e nunca zero.
